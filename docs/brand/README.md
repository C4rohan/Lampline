# Lampline brand

The mark is a switchboard lamp lit on its line: on the old cord switchboards a
lamp lit up when a call came in, and the operator connected it.

| File | Use |
|---|---|
| `lampline-mark.svg` | the mark, 32 px and up |
| `lampline-mark-small.svg` | 16 to 32 px (favicons): one arc, heavier strokes |
| `lampline-logo-light.png`, `lampline-logo-dark.png` | mark and name, for light and dark backgrounds |
| `social-preview.png` | GitHub social preview (Settings → General → Social preview), 1280 × 640 |

Colours: ink `#15212b` (dark tile `#22313f`), lamp amber `#f2b84b`. Type: IBM Plex Sans
SemiBold (SIL Open Font License, bundled with the app).
